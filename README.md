# 🏥 Hospital Emergency Room Dashboard | Excel Data Analytics Project

## 📌 Project Overview

This project is an **Excel-based Hospital Emergency Room Dashboard** designed to analyze monthly emergency room performance and provide a clear view of patient activity, waiting time, satisfaction, admission status, demographics, and department-wise patient distribution.

The dashboard helps hospital management understand patient trends and identify areas that may require operational attention.

---

## 🎯 Project Objective

The main objective of this project is to analyze Emergency Room data and create an interactive dashboard that helps answer questions such as:

- How many patients visited the Emergency Room?
- What is the average patient waiting time?
- How satisfied are patients with the emergency room service?
- What percentage of patients were admitted?
- How are patients distributed by gender?
- Which age groups have the highest number of patients?
- Which departments receive the most patients?
- How does patient activity change month by month?

---

## 📊 Dashboard Overview

The dashboard provides a monthly view of Emergency Room performance.

### Key KPIs

- **Patient Attend Status**
- **Gender-wise Analysis**
- **Age Group Analysis**
- **Department-wise Patient Distribution**

---

## 🔍 Key Insights

Based on the selected dashboard view:

- The Emergency Room handled **471 patients**.
- **247 patients (52.4%) were admitted**, while **224 patients (47.6%) were not admitted**.
- The average patient waiting time was **34.05 minutes**.
- The patient satisfaction score was **5.31**.
- **Male patients represented 52%** of patients, while females represented 48%.
- The **0–9 age group** had the highest number of patients among the displayed age groups.
- The largest department category shown was **None**, followed by **General Practice** and **Orthopedics**.
- Patient attendance status showed **56% On-time** and **44% Delayed**.

> Note: The insights above represent the selected month/year displayed in the dashboard and may change when different filters are applied.
